# AI Learning Resources

A curated collection of free AI learning resources for the Bharat AI Mission community.

Our goal is to make Artificial Intelligence accessible to students, professionals, researchers, developers, and anyone curious about AI.

We welcome community contributions to keep this list useful, accurate, and accessible.

## How to Use This List

- **Beginner:** Start here if you are new to AI.
- **Intermediate:** Best if you understand the basics and want practical experience.
- **Advanced:** For deeper technical learning and implementation.

Check each provider's website for current access requirements. Some resources may require a free account.

## Recommended Learning Path

If you are starting from scratch, consider following this sequence:

1. **Understand AI:** Start with AI Foundations or Elements of AI.
2. **Learn machine learning:** Explore Google's Machine Learning Crash Course.
3. **Build practical skills:** Work through Kaggle Learn or Microsoft's beginner curriculum.
4. **Explore generative AI:** Use Microsoft's Generative AI for Beginners.
5. **Explore open-source AI:** Continue with Hugging Face Learn.
6. **Build AI agents:** Explore the Hugging Face AI Agents Course.

Choose a path that matches your background and learning goals. You do not need to complete every resource.

## Contribution Guidelines

Help us improve this collection!

You can contribute by:

- Suggesting a new, high-quality learning resource.
- Verifying an existing link and its access requirements.
- Correcting a description or difficulty level.
- Recommending resources relevant to Indian languages and local use cases.
- Translating learning guidance into Indian languages.

Before adding a resource, please check that:

- The link works and points to the intended resource.
- The material is free to access, or any restrictions are clearly stated.
- The provider and topic are identified accurately.
- The difficulty level is appropriate for the intended audience.
- The resource provides meaningful learning value.

Please submit changes through a GitHub pull request. If you are new to GitHub, open an issue first and the community can help you contribute.
