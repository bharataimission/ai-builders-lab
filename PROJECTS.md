
# AI Builders Lab — Project Catalogue

Welcome to the AI Builders Lab project catalogue by Bharat AI Mission.

These projects are proposed starting points for community collaboration. Each project will evolve based on contributor interest, available mentors, and community feedback.

## 1. AI Learning Assistant

**Goal:** Build an assistant that helps learners understand AI concepts using curated learning resources.

**Skills:** Python, LLMs, prompt engineering, documentation.

**Starter contributions:**
- Create a curated list of beginner AI learning resources.
- Build a simple question-answering prototype.
- Add example questions and evaluation tests.

## 2. Indian Language AI Evaluation

**Goal:** Explore how AI models respond to questions in Indian languages.

**Skills:** Python, data preparation, translation, evaluation.

**Starter contributions:**
- Propose evaluation questions in one Indian language.
- Document translation and validation guidelines.
- Build a simple scoring script.

**Important:** Use appropriately licensed data and document its provenance.

## 3. Document Question-Answering Assistant

**Goal:** Build a prototype that answers questions about user-provided documents and links answers to source passages.

**Skills:** Python, retrieval-augmented generation (RAG), testing.

**Starter contributions:**
- Create a small sample document collection.
- Build a basic retrieval pipeline.
- Test whether answers are supported by source passages.

## 4. AI for Social Good

**Goal:** Explore small AI prototypes that address clearly defined community needs.

**Skills:** Research, Python, user experience, testing, domain knowledge.

**Starter contributions:**
- Propose a community problem worth exploring.
- Document user needs and possible risks.
- Develop a prototype using public or synthetic data.

## 5. AI Project Documentation Hub

**Goal:** Make practical AI projects easier for beginners to understand and reproduce.

**Skills:** Technical writing, Python, testing, instructional design.

**Starter contributions:**
- Write a beginner-friendly tutorial.
- Test an existing example and report issues.
- Improve setup instructions or diagrams.

## How to Propose a Project

1. Open an issue describing the problem and intended users.
2. Explain the proposed solution and expected benefit.
3. Identify the data, tools, and skills required.
4. Discuss privacy, licensing, safety, and evaluation considerations.
5. Wait for community feedback before starting substantial implementation.

## Project Principles

- Prefer small, useful, reproducible prototypes.
- Use open-source tools where appropriate.
- Respect licenses, privacy, and data rights.
- Document limitations and evaluation methods.
- Welcome contributions beyond code.

**Have an idea? Start a discussion with the community.**
