
# Contributing to AI Builders Lab

Thank you for your interest in contributing to AI Builders Lab by Bharat AI Mission!

We welcome contributions from students, developers, researchers, educators, designers, and AI enthusiasts.

You do not need to be an AI expert to get started.

## Ways to Contribute

You can help by:

- Building or improving AI projects
- Writing tutorials and documentation
- Testing examples and reporting bugs
- Improving code quality and accessibility
- Contributing research, evaluations, and reproducible experiments
- Supporting Indian-language resources and translations
- Suggesting ideas for useful AI applications

## Getting Started

1. Read the project README.
2. Explore the Issues tab.
3. Look for issues labelled `good first issue` or `help wanted`.
4. Comment on an issue before starting substantial work.
5. Ask questions if anything is unclear.

## Making a Contribution

1. Create a fork of the repository.
2. Make your changes in your fork.
3. Test your changes where applicable.
4. Submit a pull request describing what you changed and why.
5. Respond to feedback from maintainers.

For small documentation changes, maintainers may provide a simpler workflow.

## Contribution Guidelines

- Be respectful, constructive, and collaborative.
- Keep contributions focused and easy to review.
- Do not commit passwords, API keys, private information, or confidential data.
- Respect copyright, licenses, data rights, and attribution requirements.
- Include tests or examples when appropriate.
- Explain limitations and assumptions in AI-generated outputs or evaluations.

## Need Help?

Open an issue or start a discussion in the repository if community discussions are enabled.

For general information, visit https://bharataimission.org.

We appreciate every contribution, whether it is your first documentation fix or a substantial technical improvement.

**Let's build open-source AI together!**
